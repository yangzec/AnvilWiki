# Clover Time 中文版交付

## 范围与依据

按 `docs/handbook/zh/categories-and-locales.md` 的「加一种语言」SOP，翻译当前 10 篇英文稿，路径保持 `src/content/wiki/zh/<category>/<slug>.mdx`。已有 en／zh 配置及中文 JSON 不重复运行脚手架。

翻译标题、描述、摘要、正文、表格、FAQ、图片 alt 和图库说明；保留 slug、category、日期、标签、图片路径、版本、兑换码本体、数值及 `draft: true`。中文页面内链采用 `/zh/` 前缀并保留原目标和尾斜杠，遵循项目 `AGENTS.md` 与 `check-content` 的语言规则。公开文章不新增来源备注或缺口清单。

同时补齐五个中文站务页面（关于、隐私、条款、版权、联系）。正文和元数据从中英文 locale JSON 读取，动态名称与游戏链接从配置替换，内部链接按 locale 生成。默认英文站务页面继续保留原组件。共享模板没有新增游戏专属硬编码。

中文内容目录与英文目录一一对应，封面及图库沿用共享素材。真实译稿优先用于预览构建，缺译稿时继续采用框架原有详情回退及列表空状态，不再复制英文正文伪装中文稿。

## 验收标准

- 英文 10 篇与中文 10 篇路径匹配；50 个文章 FAQ 和 8 个图库说明完成翻译。
- 英文源稿未修改，译稿保留结构数据；中文内链全部指向同语言页面。
- 中文 UI 字段完整且清除未翻译的普通标签。
- `check-config`、`check-content`、`check-i18n --strict`、构建、链接检查通过；在隔离预览目录另跑严格 i18n，以实际验证 10/10，避免草稿被排除造成 0/0 假覆盖。
- 检查中文桌面与手机页面、标题、表格、FAQ、配图、语言切换、快速解答复制、图库与中文全文搜索；不产生页面横向溢出。
- 缺少译稿时构建保持英文回退，真实译稿不被英文覆盖；两种路径都保持 noindex 与原稿不变。

## 当前结果

已完成 10 篇中文源稿、39 个 H2 分节、50 个 FAQ、8 个图库说明与图片 alt。共享插画与操作示意图继续沿用原素材；图中的英文按钮、技能名称和示意标签未重绘。

`pnpm check-i18n --include-drafts --strict` 实际覆盖为文章 10/10、UI 166/166；隔离预览也检查 UI，源稿的中英文版本均保留 `draft: true`。新增三个覆盖率回归测试分别验证默认排除草稿、含草稿时缺译稿失败、完整译稿正确计数。

构建不再制造中文英文副本，每个语言读取自己的真实稿件，首页快捷链接使用对应中文标题。修复了首页快捷链接重复添加语言前缀的问题。语言切换器使用可读版本覆盖，hreflang 继续只使用可索引版本覆盖，避免 noindex 文章无法切换语言。

工程检查：配置、内容、严格 i18n、构建、全部链接、lint、类型检查通过；24 套件共 400 项测试通过。类型检查 184 个文件，0 错误／警告／提示，默认构建 51 个 HTML 页面、1,593 个链接全部可达。

边界验证：在一次性副本移除中文 Poison 译稿，严格覆盖正确报 9/10 并失败；预览输出英文详情回退且不在中文首页宣传该译稿，不产生伪译稿，保留 noindex 和 sitemap 排除。普通生产 Astro 构建排除全部草稿文章。源码哈希验证不变。副本的首次普通构建因 pnpm 自动安装检查而拒绝共享 node_modules 清理；使用已有 `--config.verify-deps-before-run=false` 配置复用已验证依赖后通过，未禁用 TLS 或修改锁文件。

本地浏览器验收共 46 项：10 个中文详情各检查 375／1440px、10 个英文详情保留、5 个中文站务页、3 个中文栏目、中文首页两种视口、4 个中文全文搜索、中文快速解答复制与中英文往返切换。检查标题、描述、摘要、可见 FAQ 与 JSON-LD 一致、图片正常加载、图库切换和页面无横向溢出。首次切换测试使用带严格锚点的文本选择器，未匹配链接文字两侧空格；改用可访问名称选择器后独立复测通过。所有页面保留 noindex；无语言版本的 en／zh hreflang 声明，既有 x-default 保留。

资料与测试证据保存于 `docs/clover-time/evidence/chinese-localization-20261010/`。插画文字未重绘，英文游戏 UI／技能名保留以便对照；中文文章翻译不增加新的游戏事实，正式事实验收仍为 0/10。
