3. **撤回“五个 Anti Magic 名称均已由 HUD 确证”。** P07 第 56、62 行的 Dual Slashes 可在书面卡片找到，但原 430×240 GIF 的 C 行无法可靠转录；不能排除另一写法，也不能武断换成 Dual Stance。应区分“卡片名称”与“低清 HUD 名称未确定”。此项是证据表述过强，不是已证明技能机制错误。
