## Clover Time 应该优先比较哪个种族？

想看综合被动，可以先比较**恶魔（Devil）**；重视魔力的玩法，可以先看**精灵（Elf）**。**人类与矮人混血（Human-Dwarf）**兼顾续航与成长，**矮人（Dwarf）**侧重续航与资源上限，**人类（Human）**提供基础恢复和经验收益。这份 PvE 排序按被动定位比较，选择时仍要结合魔导书与所用能力。

![Clover Time 五种种族形象的幻想主题插画](/images/articles/clover-time/races-concept.webp)

*原创概念插画。*

| 被动优先级 | 种族 | 比较理由 |
| --- | --- | --- |
| S | Devil（恶魔） | 综合生命、恢复、魔力与经验属性 |
| A | Elf（精灵） | 魔力上限与恢复，同时兼顾恢复和经验 |
| A | Human-Dwarf（人类与矮人混血） | 结合恢复、资源与经验收益 |
| B | Dwarf（矮人） | 续航与资源属性 |
| C | Human（人类） | 基础恢复与经验属性组合 |

排序比较的是被动属性组合，并非计时升级测试或伤害排行榜。它可以帮助你决定在角色面板中重点查看什么。

## 五个种族的属性方向有什么区别？

查看每个种族支持哪些属性：生命、体力、魔力、恢复和经验。**Elf** 的比较重点是魔力上限与恢复；**Devil** 覆盖的属性更广。**Human-Dwarf** 与 **Dwarf** 提供偏续航的替代方向，**Human** 则可以作为比较其他种族恢复与成长收益的基础。

| 种族 | 属性方向 | 选择时要考虑的问题 |
| --- | --- | --- |
| Human | 生命、体力和魔力恢复；经验 | 当前活动最需要哪种基础收益？ |
| Dwarf | 恢复、体力与魔力 | 是否需要续航和资源上限？ |
| Human-Dwarf | 恢复、体力、魔力与经验 | 是否想兼顾续航与成长？ |
| Elf | 魔力上限、魔力恢复、恢复与经验 | 魔法资源管理是否是重点？ |
| Devil | 生命、恢复、魔力与经验 | 综合被动是否适合当前角色？ |

把这些定位与[魔导书强度榜](/zh/guides/grimoire-tier-list/)一起比较。魔导书决定魔法工具，种族被动则支持使用这些工具的角色。

## 为什么 Sovereign 与 Chosen One 不在种族表中？

**Sovereign** 属于**社会阶层（Social Class）**，**Chosen One** 属于**特性（Trait）**。它们在角色配置菜单中与 Race 并列显示，不属于五个种族。角色配置可以组合三个类别的选项，比较配置或决定重抽类别时，要分别阅读各栏。

[重抽菜单指南](/zh/guides/how-to-reroll/)说明了 Race、Social Class 与 Trait 的区别。Mana Sensitive 也属于特性，不是第六个种族。

## 再次重抽前怎样使用这份排名？

先阅读当前种族及其显示的属性，确定玩法需要哪种收益，再与表格比较。随后一起查看社会阶层和特性。这样，选择就能围绕当前角色展开，而不是因为某个种族档位最高，就花掉所有可用的 Spins。

偏向剑术的玩法可以比较[反魔法技能组合](/zh/items/anti-magic/)。法术玩法有不同的站位工具，[毒魔法指南](/zh/items/poison/)提供了相关例子。先熟悉这些能力，再判断更换被动属性能带来多大帮助。
