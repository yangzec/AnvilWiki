## Clover Time Beta 0.1 是什么？

**Clover Time** 是 **AnimeCore Studio** 开发的动漫 RPG，Roblox 游戏简介标注其版本为 **Beta 0.1**。游戏结合了魔导书成长、动作战斗、法术组合与探索，也包含觉醒、魔法扫帚、魔法小队和挂机世界，为角色成长提供多个相互关联的系统。

## 哪些功能构成游戏成长系统？

魔导书提供魔法成长，战斗结合攻击与法术，觉醒带来变身后的魔法技能组合。**魔法扫帚（Magic Brooms）**支持飞行探索，**魔法小队（Magic Squads）**让玩家组队挑战 Boss，**挂机世界（AFK World）**则提供另一种奖励活动。根据正在使用的系统阅读对应攻略，分清操作与资源。

| 功能 | 玩家活动 | 相关内容 |
| --- | --- | --- |
| 魔导书 | 比较魔导书并发展魔法能力 | [PvE 魔导书强度榜](/zh/guides/grimoire-tier-list/) |
| 动作战斗 | 学习攻击、站位与法术 | [反魔法技能](/zh/items/anti-magic/) |
| 觉醒 | 发展变身后的魔法技能组合 | 基础能力与变身能力要分别练习。 |
| 魔法扫帚 | 飞行探索游戏世界 | [新手探索](/zh/guides/beginner-guide/) |
| 魔法小队 | 组队挑战 Boss | 比较角色在战斗中能提供的工具。 |
| 挂机世界 | 参与挂机奖励活动 | 将这些奖励与其他活动分开记录。 |

## 怎样关注更新并对照自己的平台操作？

通过 Roblox 官方游戏页面、**AnimeCore Studio** 群组与社区服务器关注游戏信息和更新预告。Clover Time 支持 **PC**、**手机**与**主机**，应按设备界面显示的操作对照动作名称。更新后，先查看受影响的系统，再决定是否花费资源更改配置。

本站页眉和页脚提供 Roblox 游戏入口。[兑换码与使用方法](/zh/codes/all-codes/)介绍活动输入框，[角色重抽](/zh/guides/how-to-reroll/)则说明与魔导书并列的角色配置类别。

| 设备 | 怎样阅读操作指南 |
| --- | --- |
| PC | 将技能或动作名称与显示的键位对应。 |
| 手机 | 使用触控界面显示的对应操作。 |
| 主机 | 将动作与该设备显示的操作对应。 |
