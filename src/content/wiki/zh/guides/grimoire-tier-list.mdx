## Clover Time 的 PvE 魔导书应该优先比较哪些？

**反魔法（Anti Magic）**与**毒魔法（Poison）**是这份 PvE 比较的优先选择：前者侧重剑术压制、移动与反击，后者组合了投射物、持续范围伤害和分身。**Ice**、**Explosive Flame**与 **Battle Lightning** 位于下一档。这些档位用于比较技能组合、决定练习方向。

![Clover Time 魔导书收藏的幻想主题插画](/images/articles/clover-time/grimoires-concept.webp)

*原创概念插画。*

| PvE 档位 | 魔导书 | 值得比较的原因 |
| --- | --- | --- |
| 第一档：优先选择 | Anti Magic（反魔法） | 剑术、接近目标的招式与反击，为近战交锋提供不同应对方式。 |
| 第一档：优先选择 | Poison（毒魔法） | 投射物、伤害雾区与分身，提供多种处理战斗的方式。 |
| 第二档：有力替代 | Ice（冰） | 范围攻击与冻结效果，使其偏向控制。 |
| 第二档：有力替代 | Explosive Flame（爆炎） | 火系技能组合更丰富，法术选择多于普通 Fire。 |
| 第二档：有力替代 | Battle Lightning（战雷） | 雷电方向的替代选择，适合与法术型角色配置一起比较。 |
| 第三档：成长选择 | Chain（锁链） | 控制招式在处理目标时提供辅助作用。 |
| 第三档：成长选择 | Snow（雪） | 召唤物为刷怪提供另一种方式。 |
| 第三档：成长选择 | Water（水） | 可以在开局成长过程中继续培养的魔导书。 |
| 第三档：成长选择 | Earth（大地） | 包含墙体与击飞攻击的成长型技能组合。 |
| 第三档：成长选择 | Fire（火焰） | 早期火系技能组合，与 Explosive Flame 不同。 |

第二档和第三档内部不分先后。表格按 PvE 技能定位安排优先级，没有给出数值伤害评分或 PvP 排名。

## 获取稀有度与 PvE 档位有什么区别？

稀有度按获取系统对魔导书分组，强度表则比较技能在 PvE 战斗中的用途。**Ice** 属于非普通，但位于有力替代组；**Anti Magic** 属于神话，提供剑术技能组合。两项信息需要结合使用，不能直接把稀有度当成战斗表现。

| 魔导书塔稀有度 | 对应魔导书 |
| --- | --- |
| Common（普通） | Earth、Fire、Snow、Water |
| Uncommon（非普通） | Ice |
| Rare（稀有） | Chain |
| Epic（史诗） | Explosive Flame、Poison |
| Legendary（传说） | Battle Lightning |
| Mythic（神话） | Anti Magic |

Fire 与 Explosive Flame 是两个独立条目。[新手入门](/zh/guides/beginner-guide/)介绍了魔导书塔标记，以及抽取使用的魔力水晶。

## Anti Magic 与 Poison 分别适合怎样的比较？

比较 **Anti Magic** 时，重点看近距离攻击、接近招式与应对压制的能力。想要投射物、伤害雾区、爆炸和分身控制时，则比较 **Poison**。关键是这些工具能否配合你的站位与目标，以及当前战斗面对的是一个敌人还是多个敌人。

## 什么时候应该继续练习当前魔导书？

当前魔导书仍能发挥作用时，继续熟悉已有招式、攻击范围与基础攻击的配合。只有能说清当前战斗缺少哪种工具，换到另一档才有明确意义。基础能力与变身能力要分开比较，同时考虑角色的魔力与恢复能力是否适合当前技能组合。

[种族被动比较](/zh/guides/race-tier-list/)介绍了这项决定的角色属性部分。角色重抽属于独立系统，花费 Spins 不会抽取另一本魔导书。
