## How do you redeem a Clover Time code from the lobby?

Find the **Codes** input at the bottom left of the lobby, beneath the screen containing **Afk World**, **Play**, and **Customize**. Select **Enter code...**, enter the promotion text, and press **Enter**. Read the response before submitting another entry so that each response remains tied to its code.

![Fantasy illustration of a Clover Time redemption desk](/images/articles/clover-time/redeem-concept.webp)

*Original concept illustration.*

1. Stay on the lobby screen.
2. Select the Codes field at the bottom left.
3. Type or paste only the code string.
4. Press Enter to submit.
5. Read the game's response.

## How can you submit a code during a game session?

Open **Menu → Settings** and find the **Codes** section while your character is in the world. Enter the same kind of promotion string used in the lobby, then submit it with **Enter**. This route lets you use the code panel from your current session without returning to the lobby.

| Starting screen | Navigation | Submission action |
| --- | --- | --- |
| Lobby | Bottom-left Codes input | Enter |
| Game world | Menu → Settings → Codes | Enter |

## What should you inspect when the entry is not accepted?

Compare the entered text with the promotion string character by character, including punctuation. Remove accidental leading spaces, trailing spaces, or copied line breaks, then read the game's response. Keep the result attached to that particular attempt; the response determines whether correcting the text is a sensible next step.

<Callout type="tip">Copy the code itself rather than a whole announcement line. A reward label or closing sentence is separate from the input text.</Callout>

Use the [codes reference](/codes/all-codes/) for the input labels and roll-resource distinctions. Avoid treating an input problem as a reason to spend character Spins.

## How do you choose the next menu after entering a code?

Return to the system you intended to progress: character rolls change **Race**, **Social Class**, or **Trait**, while the tower handles Grimoire rolls. Check the relevant balance before selecting another action. Keeping those systems separate makes it easier to understand what changed and which resource your next action uses.

Continue with [Race, Social Class, and Trait rerolls](/guides/how-to-reroll/) if you are changing character options. For the opening systems and tower marker, use the [beginner walkthrough](/guides/beginner-guide/).
